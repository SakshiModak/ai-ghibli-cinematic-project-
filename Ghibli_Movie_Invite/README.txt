# Ghibli Movie Marathon AI Project

An AI-generated cinematic project inspired by Studio Ghibli aesthetics.

This project started with a prompt-generated poster and was later transformed into an animated cinematic video using AI video generation tools.

---

## Tools Used

- ChatGPT (Prompt generation & creative direction)
- Veo 3.1 (AI video generation)
- Prompt Engineering Techniques
- AI-assisted visual storytelling

---

## Project Workflow

1. Generated a Ghibli-inspired movie marathon poster using AI prompting
2. Refined cinematic aesthetic and composition
3. Converted the poster into an animated sequence using Veo 3.1
4. Enhanced visual storytelling through motion and atmosphere

---

## Files Included

- `poster.png` → Original AI-generated poster
- `ghibli_video.mp4` → AI-generated cinematic video
- `prompts.txt` → Prompt engineering process
